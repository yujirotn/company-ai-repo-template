# projects ─ 仕事ごとのフォルダ

道具やサービスを作る仕事は、1つにつき1フォルダをここに置きます。作り方は開発の手順の道具 `ai-dev-steps` に従います（入口は `dev-start`）。

```
projects/<仕事の名前>/     名前は本人が日本語で付ける（例: 備品の貸し出し記録）
├── README.md            入口: 何の仕事か・今の段・進み具合・最近の動き（履歴）
├── docs/                仕様（コンセプト・要件・画面・データ・完成条件 ほか）と reviews/（点検の記録）
├── prototype/           試作
└── app/                 本番
```

始める時は、AI に「新しい道具を作りたい。dev-start で今どの段か教えて」と頼みます。
