# 画像の指示文の型（画像生成の道具が使える時だけ）

使ってよい画像生成の道具は、会社の決まり（`CLAUDE.md`・`DESIGN.md`）に従う。決まりが無ければ、使う前に聞く。
社外秘の情報・お客様の名前・個人情報を指示文に入れない（外部のサービスに送られるため）。

**基本は「画像は文字なし、文字は HTML」。** 画像に文字を焼き込むと、1文字直すだけでも作り直しになる。

## 共通の前置き（毎回の指示文の頭に付ける）

`DESIGN.md` から作る:

```
16:9 のスライド用の画像。平らな塗り（グラデーション・影・立体感なし）。
色は {メインの色} と {地の色} を中心に、{強調の色} は1点だけ。
写真風にしない。英字・ロゴ・透かしを描かない。
```

## 型1: 文字なしの扉絵（表紙・扉の背景）

```
余白を大きく残す。パートの扉の背景画。文字は一切描かない。
{メインの色}を基調に、右側に細い線画で「{パートを表す抽象的なモチーフ}」。
{強調の色}は1点だけ。左と下は、文字を載せるため暗い余白を大きく残す。
```

- モチーフの例: 問いのつながり／3本の柱／吹き出しから的へ／書類が流れ込む／盾とチェック／手とキーボード
- 文字なしなので崩れる心配がない。見るのは「文字が紛れ込んでいないか」だけ

## 型2: 図の画像（考え方・つながり・流れ）

HTML の SVG で描けるなら、そちらを先に考える（直しやすい）。描きにくい時だけ画像にする。

```
16:9 の図を1枚。{並べ方: 3列の比較／2×2／前後の上下対比／横3段の流れ／真ん中から放射}。
各要素は「ピクトグラム＋余白」。文字は描かない（文字は後から HTML で重ねる）。
文字を重ねる場所として、{どこ}を空けておく。
```

どうしても画像に文字を入れる時:
- 描く日本語を必ず「」で全部並べる（勝手に文を足されるのを防ぐ）。「描く日本語は上の「」の中だけ」と書き添える
- 1つの箱の文字は「見出し 10 字前後＋補足 15 字前後」まで
- **全部を1枚ずつ目で見る**。1文字の抜け（「伝えようとしない」→「伝えようとない」など）も見逃さない。崩れたらその1枚だけ作り直す

## 型3: 余白の多い1行（問いかけ・締め）

画像にしなくても、HTML で大きな文字を1行置けば足りることが多い。背景だけ欲しい時:

```
白い背景。真ん中に細い{強調の色}の線を1本だけ。ほかの要素・飾り・文字は描かない。
```

## 作る・確かめる時の決まり

- 大きさ: 全面に敷く画像は 16:9（例 1536×864 以上）。左右に分けるスライド用は正方形でもよい
- ロゴは AI に描かせない。会社の公式のファイルを後から重ねる（その分の余白を指示文で空けておく）
- 古い画像は消さずに `images/old/` に移す（戻せるように）
