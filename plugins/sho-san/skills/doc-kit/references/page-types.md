# ページの型と図の約束

## 1. 種類ごとのページの並び

### 会社紹介（3〜6ページ）
| No. | 見出しの例 | 主役の図 |
|---|---|---|
| 表紙 | 会社紹介 | 会社の言葉（ホームページの一言）＋ロゴ。下に濃い色の帯 |
| 1 | 【会社の一言】をつくる、【業種】 | 会社の概要の表（会社名・設立・所在地・代表・人数）＋強みの図 |
| 2 | 【数】つの事業で、【何を】つくる | 事業の柱をアイコン付きで横に並べる |
| 3 | 【実績の言い切り】 | 大きな数字3つ（単位と出どころつき） |
| 締め | 【これからの一言】 | 濃い色の全面＋白い大きな言葉 |

- 会社の言葉・理念は、ホームページの言い回しをそのまま使う（言い換えない）
- 取引先のロゴを並べる時は、公式のロゴを使い、載せてよいかを先に確かめる

### 戦略共有（5〜10ページ）
| No. | 見出しの例 | 主役の図 |
|---|---|---|
| 1 | 今期は【一言】に絞る | いま → 目指す姿の比べる表（2列） |
| 2 | 【柱の数】つの柱で進める | 柱ごとのカード（同じ大きさ・同じ強さで並べる） |
| 3 | まず【いちばん効く一手】から | 優先の順のはしご（上から順に） |
| 4 | 【時期】までにここまで | 時期 × 柱の表（ロードマップ） |
| 5 | 決めてほしいこと | 決めることの一覧（推奨つき） |

- 社内の数字（売上・利益）を載せる時は、出どころと時点を書く。社外に出す版では外す

### 仕組みの図解（データの流れ図・3〜4ページ）
| No. | 見出しの例 | 主役の図 |
|---|---|---|
| 1 | 全体の流れ ─ 【一言】 | データの流れ図（下の「図の約束」） |
| 2 | 【判定】の決まり ─ 上から順に当てる | はしご（縦の線に小さな印、右に答えの箱） |
| 3 | 知らせ方 ─ 何を・いつ・どこへ | 一覧表（何を／いつ／どこへ／書くこと／消える時） |
| 4 | 言葉と置き場 | 言葉の説明の表と、図の記号 ↔ 実物のファイルの対応表 |

- 実物（コード・設定・図面）があるなら、**必ず読んでから描く**。推測で描いた構成図は、無いより悪い。読めなかった所は描かずに「未確認」と書く

## 2. 図の約束（データの流れ図）

| 記号 | 意味 | 描き方 |
|---|---|---|
| 塗りの四角 | 人・外のサービス（メール・チャット・お客様） | 文字の色で塗り、白い文字 |
| 白抜きの丸 | 処理（決まった動き） | 白地＋文字の色の線。中に番号と名前 |
| 開いた箱 | データの置き場（ファイル・表・鍵の保管庫） | 上下の線だけ。左に D1・D2 の番号 |
| 強調の色の丸 | いちばん見てほしい1種類（例: AI の処理） | 強調の色で塗る。1つの図に1種類だけ |
| 点線の四角 | 境目（このパソコンの中・社内のネットワークの中） | 点線で囲み、隅に名前 |

- 矢印には、流れるもの（データの名前）を短く書く
- **線を交差させない**。交差しそうな時は、同じ人・同じ置き場を2か所に描き、「同じもの」と注記する
- 縦は上 → 下、横は左 → 右に流す
- 凡例を図の上に1行で置く

## 3. 空欄の書き方

- 分からない中身は、点線の下線（`.blank`）で空けておく。長さで中身の量の目安を示す
- 図の中の空欄は、点線の丸・点線の枠にする
- 「？」「（推測）」「ここに入れる」とは書かない
- 渡す時に、空欄の一覧（どのページのどこが空いているか）を添える
