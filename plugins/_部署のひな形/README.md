# 部署のひな形（コピーして使う型）

このフォルダは**そのまま使うものではありません**。新しい部署の道具（プラグイン）を作る時に、
このフォルダ全体をコピーして使う型です。

## 使い方

1. このフォルダ全体を `plugins/<部署名>/`（半角英数字のkebab-case。例: `plugins/sales/`）としてコピーする
2. コピーした中の `.claude-plugin/plugin.json` の `name` を、部署名（kebab-case）に書き換える
3. `skills/_ひな形スキル/` を、実際に作りたいスキルの名前のフォルダにコピー・リネームし、
   `SKILL.md` の中身を部署の実際の手順に書き換える
4. リポジトリ直下の `.claude-plugin/marketplace.json` の `plugins` 配列に、この部署のプラグインを
   1行追加する（`common` の書き方を真似ればよい）
5. `claude plugin validate ./plugins/<部署名>` で確認する

## このフォルダ自体はマーケットプレースに登録しない

`plugins/_部署のひな形` 自体は `marketplace.json` に載せていません（登録すると、まだ中身が
空のテンプレートがそのままインストールできてしまうため）。コピーして部署名に変えた後に登録してください。
