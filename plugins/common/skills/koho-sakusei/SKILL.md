# 広報物を作る

同じ会社から出るものは、いつも同じ見た目・同じ言葉づかいにそろえる。
決まりは `トンマナ.md`（このスキルと同じフォルダ）に書いてあり、毎回それに従う。

## 1. 決まりが空のとき（初回）

`トンマナ.md` の【　】が残っていたら、作り始めずに決まりを埋める。

- 質問は1回に1問。おすすめを1つ添え、「おすすめで」と言われたらそれを採用する
- 会社のホームページの URL を教えてもらえたら、まず読んで、色・書体・よく使う言葉の候補を出してから聞く
- 聞く順番: 1. メインの色と強調の色 2. 書体（和文・英字） 3. 文の調子（です・ます／体言止め） 4. 使わないもの 5. ロゴの置き場所と大きさ 6. 会社として必ず入れる言葉・入れない言葉
- 全部そろったら一覧で見せ、「OK」と言われてから `トンマナ.md` に保存する

## 2. 作るとき

1. 何を・誰に・何を伝えたいかを確認する（分からなければ1問だけ聞く）
2. `トンマナ.md` を読み、その決まりで1枚の HTML を作る（印刷・PDF にしやすい A4 か 16:9。どちらにするかは聞く）
3. 文字を並べるだけにしない。伝えたいことが1目で分かる図（流れ・比べる・数の大きさ）を1つ入れる
4. できたら保存した場所を伝え、決まりから外れたところが無いか自分で点検して報告する

## 守ること

- 決まりに無い色・飾りを足さない。迷ったら足さずに聞く
- 金額・お客様の名前・社外秘の数字は、言われても載せる前に確認する
- 写真や画像は、使ってよいと言われたものだけ使う
