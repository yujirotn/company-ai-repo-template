# ひな形の更新を取り込む

すでに会社の書庫を作っている人向けの手順です。手元にある**自社の書庫のフォルダ**で普段の AI を開き、下から合う方を選んで貼ってください。自社の書庫を変更できる GitHub アカウントを使います。プルリクエスト（変更の提案）ができたら、会社の人が差分を見て取り込みます。

## Codex に貼る文

```text
今開いている自社の書庫（作業先）の AGENTS.md を読んで。https://github.com/yujirotn/company-ai-repo-template の最新の main を参照用に取得し、この書庫と比べて、次の更新を自社の書庫に足して。

- members/ のおすすめの棚（名札のひな形に skills/ と紹介の書き方、members/見本/ のサンプル）
- CATALOG.md と自動更新（scripts/catalog.py、.github/workflows/catalog.yml）
- README の「この書庫でやること3つ」と、この更新手順のリンク先（docs/ひな形の更新を取り込む.md）
- docs/運用ルール.md の棚と一覧の案内
- AGENTS.md と CLAUDE.md の「取り込む」「載せる」の決まりと、既存の持ち寄り手順とのつなぎ

既存の会社名、DESIGN.md の内容、自社の plugins/、メンバーの名札やスキル、手元で作業中の変更は消さず、上書きもしないで。すでに同じ場所に文や設定があれば、差分を読み、必要な部分だけを足して。ひな形側への変更や、この書庫への一括マージはしないで。

自社の書庫の main を元に作業用の枝を作ってから編集し、python3 scripts/catalog.py で自社のスキル一覧を作って。差分を確認し、今回の変更だけをコミットして、自社の書庫に枝を送って main 宛てのプルリクエストを作って。最後にプルリクエストの URL と確認結果を教えて。
```
