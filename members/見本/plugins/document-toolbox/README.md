# 文書用の道具箱

読んだ文書から次の一歩を短く整理するスキルをまとめた Claude Code 向けのプラグインです。[定義](.claude-plugin/plugin.json) / [収録スキル](skills/document-next-step/SKILL.md)

本人が中身を確認したら、書庫の一番上からフォルダを指定して試せます。コマンドを実行した会話で使えます。

```bash
claude --plugin-dir "members/見本/plugins/document-toolbox"
```

文書は本人が指定します。追加の設定、フック、外部接続は含みません。使い終わったら会話を閉じます。この書庫の `LICENSE`（MIT）が適用されます。
