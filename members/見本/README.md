# 見本

会議のあとに、決まったことと次の作業をメンバーに共有する役です。

- [minutes-in-three-lines](skills/minutes-in-three-lines/SKILL.md) は、長い議事メモから次にやることを見つけたいときに使います。担当や期限が決まっていないことも見えるので、確認がしやすくなります。
- [block-inline-key](hooks/block-inline-key/README.md) は、認証情報を扱うコードを編集するときに、鍵らしい値が混ざるのを止めます。
- [no-inline-key](rules/no-inline-key/README.md) は、認証情報の置き場所をチームでそろえるときに使います。
- [document-reviewer](agents/document-reviewer/README.md) は、長い文書から決まったことと要確認の点を拾う役です。
- [limit-access](settings/limit-access/README.md) は、秘密のファイルや点検中の書き込みへの権限を絞ります。
- [document-toolbox](plugins/document-toolbox/README.md) は、読んだ文書から次にやることを整理するスキルをまとめています。
