# プラグイン

`<プラグイン名>/` に、スキル・エージェントなどを一緒に配れる道具箱を置きます。対応する AI の定義ファイルに `name` と `description`（使いどころが分かる一文）を書きます。目録は `plugin.json`、`.claude-plugin/plugin.json`、`.codex-plugin/plugin.json` の順に最初に見つかった定義を読みます。

名札には説明へのリンクと使いどころを、プラグインの `README.md` には入っている部品、必要な権限、入れ方と外し方を書きます。出典・ライセンスも残します。

棚に置くと紹介できます。使う時は本人が対応する AI に導入します。フックや設定が含まれる場合はその全文を先に本人に見せます。導入するとそれらが自動で有効になる場合は、本人が確認して手で足せる部品を選びます。[文書用の道具箱の見本](../../見本/plugins/document-toolbox/README.md)
