# 決まりの断片

`<決まりの名前>/` に、普段の `CLAUDE.md` や `AGENTS.md` に足せる短い Markdown を置きます。文面が違う場合は、どちら向けか分けて書きます。

各部品の `README.md` は先頭の `---` で囲んだ `name`（部品名）と `description`（何を守るか一文）から始めます。本文には使う場面と適用範囲を書き、名札からリンクします。

取り込む時は自分の指示書との重複や矛盾を確認し、本人に差分を見せて同意を得ます。実在の社名・人名・秘密の値や社内の数字は持ち寄る前に除きます。[鍵をコードに書かない決まりの見本](../../見本/rules/no-inline-key/README.md)
