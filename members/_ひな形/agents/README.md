# エージェント

`<エージェント名>/claude-code/` に Claude Code の `agents/*.md` 形式、`<エージェント名>/codex/` に Codex の `agents/*.toml` 形式の定義を置けます。

各部品の `README.md` は先頭の `---` で囲んだ `name`（部品名）と `description`（どんな役か一文）から始めます。本文には対応する AI、頼む場面、使う権限、必要な道具を書き、名札からリンクします。

取り込む時は定義を読み、本人が指定した AI 向けのファイルをコピーします。同名があれば先に差分を確認します。個人のパスや秘密の値を除き、フックや権限の設定が付く場合は設定の全文を先に見せます。[文書点検役の見本](../../見本/agents/document-reviewer/README.md)
