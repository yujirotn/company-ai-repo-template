# メンバーの名札（コピーして使う型）

ここは、会社の書庫の中に置く**1人分の名札とおすすめの棚**です。名札には個人の書庫の場所を、棚にはほかのメンバーにも使ってほしいスキルや見本を置きます。本人だけのスキルやメモは**個人の書庫**（本人専用の非公開の書庫）に置きます。

AI は最初にこの書庫を読んだ時、作業する人の名札を探します。名札が無い、または個人の書庫が書かれていなければ、
個人の書庫を作ることを本人に提案し、同意があれば作ってから、この名札を作ります（`CLAUDE.md` / `AGENTS.md` の「置き場所の3段」）。

## 使い方

1. このフォルダを `members/<呼び名>/`（半角英数字。例: `members/taro/`）としてコピーする
2. 下の「名札」の【　】を埋める
3. 他の人にも見せたい試作があれば、このフォルダの中に置いてよい（本番のデータ・秘密の値は置かない）

## 名札

| 項目 | 中身 |
|---|---|
| 呼び名 | 【　】 |
| GitHub のアカウント名 | 【　】 |
| 個人の書庫 | 【GitHub上の場所。例: 組織名/taro-ai（非公開）。作らないと決めた時は「作らない」】 |
| 作った日 | 【YYYY-MM-DD】 |

## おすすめのスキル

- 【スキル名】を【どんな場面】で使っています。【どんな作業が楽になったか】が気に入っています。スキルを置いたら `skills/<スキル名>/SKILL.md` へのリンクを付けます。

スキルは `skills/<スキル名>/SKILL.md` に置き、必要な付属ファイルも同じスキルのフォルダに入れます。デザインの見本など、スキル以外のおすすめもこの棚に置き、ここからリンクを張れます。

`SKILL.md` は上下の `---` で囲んだ `name` と `description` から始めます。`name` はフォルダ名と同じ半角英小文字・数字・ハイフンにし、`description` には使いどころが分かる一文を書きます。[棚の見本](../見本/)と[スキル一覧](../../CATALOG.md)も参考にしてください。

## 部署の道具への「卒業」

個人の書庫やここで試したものを**3回使って役に立つと分かったら**、部署の道具（`plugins/<部署名>/`）に
上げることを検討する。上げ方は [運用ルール](../../docs/運用ルール.md)の「成長の道」を参照。
