# メンバーの名札（コピーして使う型）

ここは、会社の書庫の中に置く**1人分の名札とおすすめの棚**です。名札には個人の書庫の場所を、棚にはほかのメンバーにも使ってほしいハーネス部品（スキル・フック・決まり・エージェント・設定・プラグイン）を置きます。本人だけのスキルやメモは**個人の書庫**（本人専用の非公開の書庫）に置きます。

AI は最初にこの書庫を読んだ時、作業する人の名札を探します。名札が無い、または個人の書庫が書かれていなければ、
個人の書庫を作ることを本人に提案し、同意があれば作ってから、この名札を作ります（`CLAUDE.md` / `AGENTS.md` の「置き場所の3段」）。

## 使い方

1. このフォルダを `members/<呼び名>/`（半角英数字。例: `members/taro/`）としてコピーする
2. 下の「名札」の【　】を埋める
3. 他の人にも見せたい試作があれば、このフォルダの中に置いてよい（本番のデータ・秘密の値は置かない）

## 名札

| 項目 | 中身 |
|---|---|
| 呼び名 | 【　】 |
| GitHub のアカウント名 | 【　】 |
| 個人の書庫 | 【GitHub上の場所。例: 組織名/taro-ai（非公開）。作らないと決めた時は「作らない」】 |
| 作った日 | 【YYYY-MM-DD】 |

## おすすめのハーネス部品

よく使う場面と、どんな作業が楽になったかを一言で書き、部品の説明にリンクします。

- 【部品名】を【どんな場面】で使っています。【どんな作業が楽になったか】が気に入っています。

| 種類 | 置き場所と書き方 |
|---|---|
| スキル | [skills/](skills/README.md) |
| フック | [hooks/](hooks/README.md) |
| 決まり | [rules/](rules/README.md) |
| エージェント | [agents/](agents/README.md) |
| 設定 | [settings/](settings/README.md) |
| プラグイン | [plugins/](plugins/README.md) |

[棚の見本](../見本/)と[ハーネス部品一覧](../../CATALOG.md)も参考にしてください。
デザインの見本などもこの棚に置いて紹介できます。

## 部署の道具への「卒業」

個人の書庫やここで試したものを**3回使って役に立つと分かったら**、部署の道具（`plugins/<部署名>/`）に
上げることを検討する。上げ方は [運用ルール](../../docs/運用ルール.md)の「成長の道」を参照。
