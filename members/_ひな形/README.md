# メンバーの試作置き場（コピーして使う型）

ここは、個人が「まだ部署の正式な道具にする前の、試しに作っているもの」を置く場所です。

## 使い方

1. このフォルダを `members/<ニックネームなど>/` としてコピーする
2. 試作中のメモ・下書きのスキル・検討中のスクリプトなどを、自分のフォルダの中に自由に置く
3. 本番のデータや秘密の値は置かない（`CLAUDE.md` / `AGENTS.md` の「毎回守ること」を参照）

## 部署の道具への「卒業」

同じ試作を**3回使って役に立つと分かったら**、部署の道具（`plugins/<部署名>/`）に昇格させることを検討する。
昇格の流れは `docs/運用ルール.md` の「成長の道」を参照。

試作をここに置いている間は、他のメンバーへの影響はありません。壊れていても誰も困りません。
気兼ねなく試してください。
