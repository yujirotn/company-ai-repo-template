# フック

`<フック名>/` に台本と設定の断片を置きます。Claude Code 用は `claude-code/` に `settings.fragment.json`、Codex 用は `codex/` に `hooks.fragment.json` を置きます。共通の台本は `<フック名>/` 直下に置けます。

各フックの `README.md` は先頭の `---` で囲んだ `name`（部品名）と `description`（何をするか一文）から始めます。本文には動く機会、対象のツール、必要なもの、止める条件、試し方と外し方を書きます。名札からこの説明へリンクします。

フックは設定に入れると命令を自動で実行します。使う人に台本と設定の全文を見せ、本人が自分の設定に手で足します。秘密の値・個人のパス・意図しない書き込みや通信がないか共有前に確かめます。[鍵らしい記述を止める見本](../../見本/hooks/block-inline-key/README.md)
